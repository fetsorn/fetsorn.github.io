# layout

 - `index.html`, `src/index.jsx` and `src/index.css` files initialize solid.js rendering.
 
## App

 - change repo 
 - show git commit 

## Layout Profile

 - show Navigation Revert, Navigation Save, Profile

## Layout Overview

 - show Navigation Back, Navigation New, Filter, Overview

## Overview

screen with a list of records

 - no items, show "new"
 - items, show UUID

## Overview Item

a short description of a single record

 - show UUID

## Overview Field

list of branch values

 - no items, show "field no items"
 - items, show record

## Overview Field Item

list of branch values

 - show value
 - show record

## Overview Record

object value

 - no items, show "record no items"
 - show value

## Overview Value

string value

 - show uuid

## Filter

component with a search bar

 - show Filter Count, Direction, Option, Query, Scroll

## Filter Count

a label with the number of search results

 - show 0
 - show 1

## Filter Direction

a switch for sorting direction

 - ascending
 - descending

## Filter Option

a button with a search keyword

 - show field

## Filter Query

an input with a search query
 
 - changes
 - removes

## Filter Scroll

a button to scroll to the top

 - show "scroll to top"

## Profile

screen for changing details of a record

 - show Profile Record

## Profile Field

list of branch values

 - removes each
 - removes this

## Profile Field Item

list of branch values
 
 - object

## Profile Record

object value

 - adds branch
 - adds another branch
 - adds description

## Profile Value

input for a value

 - show value

## Asset View

media file of any format

## Confirmation

a dialogue for destructive side-effects

 - no
 - yes

## Navigation Back 

button to the home screen

 - return to root

## Navigation New

button to create

 - call on record create 

## Navigation Revert 

button to cancel changes

 - reset record

## Navigation Save

button to save changes

 - call on record save

## Spoiler

a dialogue to unfold details

 - opens
 - closes
