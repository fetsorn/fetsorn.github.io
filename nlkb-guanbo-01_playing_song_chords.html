Playing song chords

Reusing functions from the tutorial, let's play notes of a chord

import { Chord } from "tonal";

//...

// ["C4", "E4", "G4", "B4"]
Chord.notes("maj4", "C4").map((note) => {
  const midi = Midi.toMidi(tone);
  
  play(midi);
  
  send(midi);
})
