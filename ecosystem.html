Ecosystem

csvs - comma separated value store
docs
A single standard I use to store all kinds of stories. "Alice fell in love with Bob on May 4th 1986" becomes

-.csv
event,name
event,date

event-name.csv
love at first sight,alice
love at first sight,bob

event-date.csv
love at first sight,1986-05-04

@/love at first sight
Fell in love

son - Store Object Notation
docs
Another way to represent a story.
{ :, event: [ date, name ] }
{ _:event, event: love at first sight, @: fell in love, name: [alice, bob], date: 1986-05-04 }

csvs-lib - plain text relational database
codeberg github docs
Code that helps to read and write csvs. Queries thousands of entries in under a second. I ask for all names in the store
{ _: name } -> [alice, bob]

mind - stories that live
docs
A mind is a csvs dataset plus everything it needs to live on its own - history of changes, docs, website, scripts.

mindzoo - dataset multiplexer
codeberg github docs
A single mind that keeps record of other minds and gives access to them.
{ _: mind, category: love } -> { _: mind, mind: Barries }
Barries, { _: name } -> [alice, bob]

mindbook - stories on a page
codeberg github docs
Shows a story as text. Makes it easier to read and edit many stories.
{ _:event, event: love at first sight, name: [alice, bob], date: 1986-05-04, @: fell in love } -> "event fell in love with: alice, bob 1986-05-04"

Evenor - event editor
codeberg github docs
Connects mindzoo and rihla to mindbook, runs on every device. In the browser stories are saved for a week, on desktop and mobile they live forever.
Try it

Wuyong - stories in a blog
codeberg github docs
A JavaScript 11ty plugin that generates a static website from csvs.
Art - try it source open in evenor
This website - source open in evenor

Panrec - dataset converter
codeberg github docs
Shows a dataset as a stream of SON records. I use it to create minds from social media, backups, gedcom, org-mode and other minds.

Alhidad - turn everything to text
codeberg github docs
Walks a hard drive, transcribes every file to text and writes into a mind. Audio with whisper ai, rich documents with pandoc.

Rihla - filtered replication
codeberg github docs
Creates a new mind from a part of an old one. I use this to split and merge minds.

Tsugiki - three trees
codeberg github docs
I use csvs to translate texts one story at a time.
