## Build

```sh
npm install
npx @11ty/eleventy
```

## Content

The csvs dataset lives in [csvs/](csvs/). Content is organized
as places:

- **specs** 
- **dialogues** 
- **devnotes** 
- **brochures** 
- **archive**
